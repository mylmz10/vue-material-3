## Using the examples

Examples on each page run directly in this documentation site. Copyable usage snippets include component imports and state initialization. Load the package stylesheet and fonts once as described in [Installation](/guide/installation).

Storybook provides additional variants and Controls. Links open the published Storybook; for local development, run `npm run storybook` and use `http://localhost:6006`. `npm run docs:dev` starts VitePress only.
